# React Google Places Search

## Technologies

- React (Vite)
- Redux Toolkit
- Redux Thunk
- Axios
- Material UI

## Features

- Search Place
- Search History
- Add Favourite
- View Favourite Places
- Delete Favourite

## Run

```bash
npm install
npm run dev
```

Frontend

```
http://localhost:5173
```

Backend

```
http://localhost:8080
```
