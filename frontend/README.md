# Places API (Spring Boot)

## Technologies

- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Swagger (OpenAPI)

## Features

- Add Favourite Place
- Get Favourite Places
- Delete Favourite Place
- REST APIs
- Swagger UI

## Run

```bash
mvn spring-boot:run
```

Swagger UI

```
http://localhost:8080/swagger-ui/index.html
```

## Database

Database

```
placesdb
```

Table

```
favorite_places
```
